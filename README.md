# ChemHazard

**Toward Formal Verification of Hazard Constraints in AI-Generated Chemical Transfer Sequences**

ChemHazard is a Lean 4 framework designed for pre-execution, machine-checkable verification of structured experimental procedures generated by AI systems. As large language models (LLMs) increasingly generate executable scripts for laboratory automation, they introduce safety risks—such as directing reagents in an unsafe order that could cause heat release or physical hazards. 

ChemHazard models protocol safety not as a static list of substances, but as a per-step precondition evaluated against the current symbolic state of destination vessels.

## Core Thesis
The central premise of ChemHazard is that the safety of AI-generated chemical transfer sequences is naturally a property of intermediate states. For example, adding acid to water and adding water to acid result in the same final mixture, but the latter violates standard safety guidance and can cause violent splattering. ChemHazard catches these order-sensitive hazards by evaluating guard predicates immediately before a transfer is applied.

## Features

* **Substance Ontology**: Models a curated set of hazard classes (e.g., `strongAcid`, `peroxide`, `aqueous`) and coarse concentration buckets (`dilute`, `moderate`, `concentrated`).
* **Protocol Modeling**: Treats an AI-generated protocol as a finite ordered sequence of symbolic transfers. 
* **Per-Step Guard Evaluation**: Uses a forward fold to check state safety before every transfer.
* **Core & Extensible Rules**: 
    * Implements the standard acid-dilution rule (blocks adding an aqueous transfer into a vessel that already contains concentrated acid).
    * Supports protocol-specific extensions, such as tightened policies for ELISA stop-solutions to prevent adding concentrated acid to peroxide.
* **Compositional Meta-Theorems**: Features a discharged, kernel-checked theorem proving that if two protocols are safe in isolation and operate on disjoint vessel sets, their concatenation is safe.

## Project Structure

* `ChemHazard/Basic.lean`: The core formalization containing the substance ontology, state definitions, transfer logic, and compositional theorems.
* `lakefile.toml`: The Lean build configuration file. 
* `lake-manifest.json` / `lean-toolchain`: Standard Lean 4 project configuration.
